# OmSaravanaBhava

Next-generation Murugan devotional knowledge flagship.

Status: bootstrap foundation created 2026-09-01. Production domain cutover is intentionally gated until the first release passes exact-head CI, GitHub Pages deployment, live-route smoke, accessibility, PWA/offline, metadata/SEO, and rollback checks.

Legacy production remains preserved independently in `ssakthivel02/kandan-legacy` at `kandan.omsaravanabhava.org`.

## Product direction
- Tamil-primary, bilingual-friendly
- Murugan / Skanda / Subramanya discovery with source-aware content boundaries
- Cinematic, accessible, responsive interaction
- Search, guided exploration, audio, temple, hymn and learning pathways
- PWA/offline-ready foundation
- AI guidance only where evidence, source labels and safety boundaries are explicit

## Release rule
Never overwrite the Kandan legacy repository. Build and validate the flagship independently, then perform a controlled domain handoff only after production evidence is green.
