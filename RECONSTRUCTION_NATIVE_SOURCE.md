# OmSaravanaBhava Native R6 Reconstruction Contract

## Authority
Recovered Manus R6 Final Master is the next visual/source authority. The existing Kandan-derived build/overlay is rollback and content-comparison material only; it is not the visual authority for the next release.

## No-donor UI rule
Do not use Kandan, DivyaNexus, RamaVerse, KirthiVerse or SakthiAI as visual/layout donors. Any donor reuse must be limited to verified missing content, provenance or rollback evidence and must not import donor visual grammar.

## Native design target
An unmistakably Murugan devotional knowledge universe: Vel-centric identity, pilgrimage/temple discovery, songs/mantras/audio, source-aware knowledge, Tamil-first devotional depth and immersive but respectful motion. Avoid generic dashboard styling and avoid reproducing Kandan's hero/navigation/card system.

## Asset reconciliation
The recovered export documents unresolved referenced assets. Resolve, replace with rights-safe originals, or explicitly quarantine each unresolved reference before production. Never silently ship broken or unlicensed visual references.

## Required gates before main
- Native R6 clean build.
- Source-fidelity comparison against recovered R6.
- Core devotional routes/content/functionality preserved.
- Desktop/tablet/mobile visual QA.
- Audio/PWA/offline behavior verified where applicable.
- Accessibility, keyboard and reduced-motion support.
- Performance budget for image/audio-heavy sections.
- No cross-site duplication of hero, nav, card grammar, background treatment or motion grammar.
- Current production remains rollback-safe until exact R6 candidate is proven.

## Release rule
No more rename-and-overlay production releases. The next release must be a native-source reconstruction with explicit content/asset reconciliation.
